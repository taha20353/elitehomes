# EliteHomes

Responsive real estate website built with HTML, CSS, and Bootstrap 5.3.8.

## Structure

```text
index.html
favicon.png
images/
style/
vendor/bootstrap/
```

Open `index.html` in a browser or serve this folder with a local static server.
All images and Bootstrap assets are included locally. Interactive components use
Bootstrap's official bundle; the site has no custom JavaScript.

The contact form and chat are demonstration interfaces, without a backend.
